# Sin District: Online — playable web build

Play here: **https://sindistrictmayor.github.io/sin-district-play/**

This repository holds only the static web export of the offline client. Open the link in a phone or desktop browser — no install and no sign-in. Progress is saved in that browser (clearing site data starts a new game).

The game source stays in the private `sin-district-online` repository. This folder is a built bundle, not the source tree.
